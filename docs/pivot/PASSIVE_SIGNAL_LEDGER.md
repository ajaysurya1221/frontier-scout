**How to use this:**
- *Source* = GitHub issue #, DM, HN/Reddit thread, repo star/fork, etc.
- *Signal type* = feedback-form / export-request / bug / unsolicited-comment / star / fork.
- *Confidence* = `weak` for a star/fork or a one-line comment; `medium` for a detailed issue with a real
  repo/process described; `strong` is reserved — a passive channel rarely earns it. A *strong* signal is
  a prompt to **recruit that person into a real session**, not to skip the gate.
- *Counts toward human gate?* is **always No**. Only a facilitated session recorded in
  [`VALIDATION_LEDGER.md`](VALIDATION_LEDGER.md) moves the 0/5.
